# Retail Superstore Sales Analytics Dashboard

## Project Overview
This project analyzes Retail Superstore sales data using MySQL, Python and Power BI.

## Tools Used
- MySQL
- Python
- Pandas
- SQL
- Power BI

## Features
- SQL data extraction
- Data analysis using Python
- Sales and Profit analysis
- Interactive Power BI dashboard
- KPI cards and filters
